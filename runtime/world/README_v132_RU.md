# v132 — метаданные и расширенные ID блоков

Legacy Anvil reader теперь дополнительно разбирает массивы Data и Add каждой секции:
- Data: 4-битные метаданные верхнего блока (ориентация/вариант);
- Add: старшие 4 бита ID блока для расширенных legacy ID;
- API отдаёт 16-битный block_id и metadata для каждой из 256 колонок.

Рендерер использует метаданные шерсти для выбора цвета, добавляет отдельный цвет лавы и расширяет таблицу распознаваемых блоков.

Это всё ещё упрощённый top-surface renderer: он не строит внутренние слои блоков и не воспроизводит точную геометрию/освещение Minecraft.
