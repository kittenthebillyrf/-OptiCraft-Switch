# v131 — подгрузка области при переходе между чанками

Игрок теперь хранит мировые координаты X/Z. Когда он пересекает границу центрального чанка, порт заново читает область 3×3 вокруг нового положения. Это позволяет перемещаться за пределы первоначального квадрата чанков, не оставляя камеру на старой карте.

- Обновляются мировые координаты игрока при перемещении.
- Перезагрузка выполняется только при выходе из центрального чанка.
- Для продолжения режима сохранения требуется успешно прочитать центральный чанк; соседние могут отсутствовать.
- Каждая загрузка повторно вычисляет координаты MCA-регионов, включая отрицательные.

Ограничения: сейчас область из девяти чанков перечитывается целиком при каждом переходе между чанками; нет фоновой загрузки, очереди IO, сохранения изменённых блоков или полного Java runtime.
