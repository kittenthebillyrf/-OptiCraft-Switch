# v136 — вертикальные слои блоков в колонке

Anvil reader сохраняет до восьми верхних непустых блоков каждой колонки:
- 16-битный ID блока;
- высоту слоя Y;
- 4-битные метаданные.

Боковые грани рендерятся полосами: для каждой полосы выбирается текстура соответствующего блока из вертикальной последовательности. Это позволяет видеть грунт/камень/песок под верхним блоком вместо одной повторяющейся текстуры стены.

Ограничение: сейчас сохраняются только восемь верхних непустых блоков и они равномерно распределяются по видимой боковой грани. Это не точная полная 3D-сетка и не заменяет полноценную геометрию блоков.
