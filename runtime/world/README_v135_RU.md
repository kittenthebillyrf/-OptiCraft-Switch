# v135 — высоты из сохранённого мира

Рендерер теперь сохраняет абсолютную высоту верхнего блока из Anvil-чанка вместо грубого уровня 0–3. Из неё вычисляется вертикальное смещение изометрической поверхности, а маркер игрока поднимается на высоту своего столбца.

- Высота столбца берётся из реально прочитанного массива Blocks.
- Разница высот становится заметнее на холмах и склонах.
- В HUD отображаются мировые координаты X/Y/Z игрока.
- Синтетическая тестовая карта продолжает использовать свои небольшие высоты.

Ограничение: это всё ещё упрощённая поверхность колонок, а не полный воксельный рельеф. Боковые стенки не восстанавливают точную последовательность всех блоков под поверхностью.
