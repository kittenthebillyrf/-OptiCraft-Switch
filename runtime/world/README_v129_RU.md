# v129 — чтение настоящего Anvil-чанка около точки появления

Добавлен отдельный загрузчик одного legacy Anvil-чанка:
- вычисляет координаты чанка/региона по SpawnX/SpawnZ;
- читает таблицу секторов MCA;
- поддерживает типы сжатия GZIP (1), zlib (2), raw (3);
- извлекает Level/Sections[*]/Y и Blocks[4096] для формата Java 1.2.x;
- формирует 16×16 верхних блоков и их высоты.

Ограничение: пока загружается только один чанк, в котором находится точка появления. Это первый настоящий срез сохранённого мира, не полная загрузка карты. Современные палитровые чанки не поддерживаются этим legacy-парсером.
