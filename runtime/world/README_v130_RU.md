# v130 — соседние чанки вокруг точки появления

Диагностический рендерер расширен до сетки 48×48 блоков и пытается загрузить область 3×3 чанка вокруг SpawnX/SpawnZ выбранного сохранения.

- Для каждого из девяти чанков вычисляются его собственные координаты MCA-региона.
- Успешно прочитанные 16×16 столбцов копируются в общую карту.
- Отсутствующие/повреждённые соседние чанки пропускаются; если ни один чанк не читается, остаётся тестовая карта.
- Индикатор показывает число реально загруженных чанков из девяти.

Это ещё не полноценный Minecraft streaming: карта ограничена окном 3×3 вокруг точки появления, не подгружается при перемещении игрока, а блоки пока сводятся к нескольким типам верхней поверхности. Сущности, освещение, метаданные блоков, пещеры и сохранение изменений ещё не подключены.
