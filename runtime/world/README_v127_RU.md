# v127 — обнаружение Java-миров на SD-карте

Добавлен каталог сохранений для Switch:
`sdmc:/switch/opticraft/saves/<folder>/`.

Папка считается сохранением, если содержит `level.dat` или резервный `level.dat_old`.
Сканер не меняет и не перезаписывает файлы мира. Он возвращает имена папок и признак наличия основного `level.dat`.

В тестовом NRO список показывается в диагностической панели. Это пока только обнаружение сохранений: декодирование NBT/Anvil остаётся отдельным reader v126, а передача загруженных блоков в Minecraft renderer ещё не реализована.

Проверка:
`sh runtime/world/tests/run_world_catalog_test.sh`
