# v134 — текстуры верхней и боковых граней

Текстурный рендерер теперь накладывает atlas не только на верхний ромб блока, но и на обе боковые грани изометрической ячейки.

Для grass block и log используются отдельные координаты боковой текстуры; остальные базовые типы используют доступный atlas tile как fallback. Альфа-канал PNG смешивается с уже нарисованной поверхностью.

Ограничение: это всё ещё упрощённая геометрия одного верхнего блока на колонку. Нет полноценной 3D-модели каждого блока, прозрачной сортировки, анимации жидкостей, освещения или текстур GUI/предметов.
