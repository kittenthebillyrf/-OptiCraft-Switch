# OptiCraft Switch — milestone 0.1: первый интерактивный мир

## Цель
Перестать ограничиваться диагностическим экраном NRO и получить первый интерактивный игровой прототип на Nintendo Switch. На этом этапе выбран нативный libnx renderer: это позволяет проверить реальный цикл игры, framebuffer, ввод и базовую механику мира до подключения JVM.

## Реализовано
- Horizon OS homebrew entry point и libnx application loop;
- HID polling для Handheld и Player 1 FullKey;
- framebuffer 1280×720 и CPU-отрисовка;
- изометрическая карта 16×16 с процедурным распределением Grass, Water, Sand и Stone;
- игрок, камера, перемещение с D-pad / левым стиком;
- целевая клетка перед игроком;
- установка Wood / Brick кнопкой A, удаление поставленного блока кнопкой B;
- смена блока X, генерация нового мира Y;
- HUD с координатами и подсказками.

## Следующая последовательность работ
1. Получить успешную сборку NRO в GitHub Actions и проверить запуск на Switch.
2. Добавить управление камерой правым стиком и нормальную обработку повторов кнопок.
3. Разделить world state, renderer и input на модули.
4. Добавить инвентарь, выбор слота, сохранение/загрузку мира.
5. Подключать существующий JVM runtime по частям, начиная с bootstrap и класса Minecraft, не ломая рабочий нативный игровой цикл.
6. Постепенно заменить временную графику ресурсами оригинального Minecraft 1.2.5.

## Важная граница
Версия 0.1 не содержит оригинальный Minecraft Java 1.2.5, JVM или OptiFine. Это минимальный игровой прототип для Switch, а не завершённый порт. Успешная CI-сборка подтверждает создание NRO, но запуск на реальной консоли подтверждается только отдельным тестом на устройстве.
