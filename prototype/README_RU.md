# OptiCraft Switch — первый игровой прототип 0.1

Это первый **интерактивный игровой NRO**, а не только диагностический экран. Приложение запускается нативно на Horizon OS через libnx и показывает небольшой процедурно созданный изометрический мир.

## Управление
- D-pad / левый стик — перемещение.
- A — поставить выбранный блок перед игроком.
- B — убрать поставленный игроком блок.
- X — переключить Wood / Brick.
- Y — создать новый мир.
- + — выйти.

## Уже реализовано
- нативный цикл приложения Switch;
- опрос Joy-Con / Pro Controller через libnx HID;
- программная отрисовка изометрических блоков в framebuffer 1280×720;
- процедурная генерация карты 16×16;
- движение игрока и камера, центрированная на игроке;
- выбор целевой клетки, установка и удаление блоков;
- HUD с координатами и подсказками.

## Честные ограничения
Это **первый игровой прототип порта**, но пока не запуск оригинального Minecraft Java 1.2.5 и не готовый OptiFine-порт. В этой сборке ещё нет JVM, Minecraft-классов, оригинальных текстур, сохранения мира, инвентаря, мобов или мультиплеера. Сейчас задача — получить реальный интерактивный NRO, затем поэтапно заменить прототипные подсистемы компонентами оригинальной игры.

Сборка: GitHub Actions workflow `Build OptiCraft playable Switch prototype`. После успешной сборки NRO доступен в Actions → Artifacts.
